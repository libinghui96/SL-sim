# SL-sim

浏览器里运行的 live steam（真蒸汽）机车模型模拟器。目标车型是 Aster Hobby 的 1 号轨 **JNR D51 标准型（重装备仕样）**：酒精灯芯燃烧器、滑阀、Walschaerts 配气机构。

它做三件事：

- **物理模拟**：锅炉、燃烧、配气、气缸、整车运动联在一起算，操作的因果关系与实车一致。
- **可操作**：按说明书的流程点火、升压、暖缸、起步、给水。
- **看得见原理**：3D 剖视、流向动画、机构拆解，加上三张联动的 2D 原理图。

## 运行

需要 Node.js 20 以上。

```bash
npm install
npm run dev      # 打开 http://localhost:5173
npm test         # 物理核心的单元测试
npm run build    # 生产构建，输出到 dist/
```

在线版本：<https://libinghui96.github.io/SL-sim/>（每次推送到 main 后由 GitHub Actions 自动构建发布）。

自己托管：先 `npm run build`，再 `docker compose up -d`，网站在本机 9696 端口。之后更新只需重新构建，不用重启容器。

## 怎么开车

左上角的“下一步”会根据当前状态提示该做什么。冷态起步的完整流程（与说明书一致）：

1. 把**燃料阀**开到约 50%。
2. 勾选**烟囱通风机**。冷态没有蒸汽，只能靠它抽风，否则火很弱。
3. 点**点火**。嫌升压慢，可以把时间倍率调到 20×。
4. 压力到 1.5–2 kgf/cm² 后，取消通风机，把**通风阀**开到约 30%，继续升到 4 kgf/cm²（安全阀起跳）。
5. 勾选**气缸排水阀**，慢慢打开**加减阀**到 25–30%。气缸是冷的，蒸汽先在缸里凝结，大约半分钟后缸壁热起来才会起步。
6. 起步后取消排水阀。用加减阀控制速度，用**旁通阀**把水位保持在 50% 左右。

不想等，点顶部的“热态开始”，直接从有压、暖缸的状态出发。

| 操作 | 作用 |
|---|---|
| 加减阀 | 控制进入汽室的蒸汽量，也就是速度 |
| 回动手柄 | 前进 / 后退；拉向中立会缩短截断比，省汽 |
| 通风阀 | 用锅炉蒸汽向烟囱吹风，停车或升压时维持火力 |
| 烟囱通风机 | 冷态升压用的电动抽风机 |
| 燃料阀 | 酒精供给 |
| 旁通阀 | 0% 时轴泵打出的水全部进锅炉，100% 时全部流回水柜 |
| 气缸排水阀 | 排出冷缸里的凝水 |
| 手摇泵 | 停车时手动给水 |

## 怎么看原理

顶部工具栏：

- **语言**：简体中文 / 日本語 / English，切换界面、原理图、3D 标注与提示；保存选择，不重置仿真。
- **相位**：桌面和紧凑布局都有常显入口，一键打开“仪表”并返回相位看板顶部；不会暂停或重置仿真。
- **视图**：
  - 外观：完整外形。
  - 剖视：外壳半透明，能看到内锅炉的水位和蒸汽、两根烟管和插在里面的过热器、穿过锅炉的蒸汽干管和通风管、燃烧器的三根灯芯、活塞和滑阀。
  - 机构：隐去车身，传动和配气零件各用一种颜色。
- **流向**：场景变暗、车身变淡，只突出管路。每种介质固定一种颜色（给水、旁通回水、饱和蒸汽、过热蒸汽、排汽、酒精、烟气、传热），管上的箭头按实际流量移动，旁边标实时数值。点图例里的某一项可以单独隐藏或显示这种介质。视图太窄时（手机竖屏）不显示数值标签，数值看“汽水与热量”原理图。
- **标注**：在 3D 里标出部件名称；机构视图下标的是各根杆件。
- **拆解**：把车身、内锅炉、驾驶室、煤水车和两侧的机构分层拉开。
- **时间倍率**：0.1× 和 0.25× 用来慢放看机构动作。

底部的原理图有三页，都画的是**右侧**，前方向右，与 3D 里从右侧看过去一致：

- **气缸与滑阀**：纵剖面。蒸汽空间按压力着色，汽口打开时有箭头指示流向。右边的圆环是配气相位图，显示一转之内前后两端的进汽、膨胀、排汽、压缩各占多少。
- **配气机构**：Walschaerts 机构的侧视联动图，颜色与 3D 机构视图一致。拖动回动手柄，可以看到滑块在月牙板上的位置和阀行程的变化。
- **汽水与热量**：全车流程图。水、蒸汽、燃料、热量各走各的管线，标有实时流量和功率，底部一行是能量去向和总效率。

右侧面板包含相位监视、压力表、水位计、各项读数和右缸的示功图（P–V 图）。相位看板显示左右曲柄、回动曲柄销角度、活塞和滑阀位移、汽口开闭、四轴同步，以及轴泵偏心轮和柱塞的位置、速度与吸水/压水状态。

暂停后可拖动左曲柄角度或点选 0° / 90° / 180° / 270° 检查机构；这会重置气缸状态，但不改变锅炉、时间和燃料。运行中禁止定位。看板汽口表示几何开闭，不保证有实际蒸汽流动。

轴泵方向对照组装图 6 和说明书印刷第 22 页（PDF 第 23 页）图 6.2：泵缸与柱塞沿车身纵向水平布置，柱塞前后往复；止回阀腔沿车宽横向布置，内有两只钢球，不是柱塞上下运动的立式泵。相位看板的泵图是侧视图；阀球启闭是随吸水/压水行程变化的示意，未求解阀球动力学。尺寸、高度和安装相位仍为估计。

烟箱内三路分开：过热器出口经总管分到左右汽室；左右气缸排汽汇入主排汽喷口；通风管接独立喷嘴。两个喷口向烟囱排放，顶部开口不是缺失的接管。实体管与流向共用连接坐标，拆解时隐藏连接管，避免显示悬空接头。

窗口宽度不超过 1200 px 或高度不超过 600 px 时（手机、平板）换成紧凑布局：3D 视图单独占一块，“操作 / 仪表 / 原理图 / 设置”四个面板一次只显示一个，用标签栏切换，最右的按钮可以收起面板。竖屏时面板在下方，横屏时在右侧。原理图在窄面板里可以左右滑动。

## 模型

物理核心在 [src/sim](src/sim)，不依赖界面，可以单独测试。

| 部分 | 做法 |
|---|---|
| 水蒸气物性 | IAPWS-IF97 饱和线公式，加蒸汽表插值 |
| 锅炉 | 饱和汽水两相的质量和能量守恒，含金属热容和散热 |
| 燃烧 | 燃烧速率随抽风变化；抽风来自通风机、通风阀和排汽 |
| 配气机构 | 按 Walschaerts 的几何逐点求解，得到阀位移和各配气事件 |
| 气缸 | 4 个缸端分别计算进汽、膨胀、排汽、压缩；含冷壁凝结、滑阀和活塞泄漏 |
| 走行部与轴泵 | 四根动轴同侧同步，第三动轴接主连杆并驱动轴泵；给水量按偏置柱塞机构的实际压水行程积分，支持正反转 |
| 整车 | 一维运动：黏着与空转、摩擦、滚动阻力、坡道、拖重 |

集总参数模型，不做流场计算。烟和蒸汽的外观是粒子特效，不参与物理。

### 参数来源

热力、配气及整车参数在 [src/sim/params.ts](src/sim/params.ts)，每一项都标了来源；动轴布置与轴泵几何在 [src/sim/runningGear.ts](src/sim/runningGear.ts)：

- `[M]` 来自 Aster 说明书：缸径 15 mm（活塞环 PR-15）、回动曲柄半径 7 mm、工作压力 3–4 kgf/cm²、安全阀 4 kgf/cm²、酒精 130 mL。
- `[P]` 按原型 D51 以 1:30 换算：行程、动轮直径。
- `[E]` 估计值：连杆长度、滑阀余面和汽口、锅炉容积、各部分质量、传热和泄漏系数等。**大多数参数属于这一类。**

### 与说明书的对照

| 说明书 | 模拟 |
|---|---|
| 点火后 2–5 分钟开始升压 | 约 3 分钟 |
| 安全阀在 4 kgf/cm² 起跳 | 4.0 起跳，3.7 回座 |
| 130 mL 酒精约运行 20 分钟 | 拖 6 kg、1 m/s 时约 20 分钟 |
| 运行中保持 3–4 kgf/cm²、水位 50% | 调旁通阀可以保持 |

这些数字是调整燃烧、泄漏、摩擦等估计参数拟合出来的，不是模型独立预测的结果。

## 局限

- 多数尺寸是估计值。在用实车测量（行程、连杆长度、滑阀余面、锅炉水容量、车重）替换之前，结果只能当作趋势和量级，不能用于定量的设计验证。
- 配气拓扑按图 9：前死点时回动曲柄销在轴心上方，半径杆接合并杆上销、阀杆接中销，气缸两条汽道交叉但不互通。具体连杆长度和回动曲柄设定角仍依赖估计几何；左右 90° 交角中的右侧超前是模型约定。轴泵安装相位、尺寸和每转排量也是估计，不能用图 9 的配气曲柄角代替轴泵偏心角。
- 3D 外形按 D51 标准型的主要尺寸和特征程序生成：轴距、锅炉高度、总长、箱形动轮、除烟板、烟囱前横置的给水加热器、集烟装置和重油箱。锅炉内部的零件数量对照了说明书和组装图：烟管 2 根；过热器 1 件，由两根 U 形管组成，各插入一根烟管；灯芯 3 根（说明书第 10 页的结构示意图、组装图 17 和 23、零件表 17-5）。管径、长度、位置和 U 形管的朝向仍是估计值。
- 烟管和过热器目前只体现在 3D 模型、流向和原理图里。物理计算仍是集总模型：烟气向水的传热用一个拟合的总系数，过热度用一个总量，没有按每根管子的换热面积计算。
- 轨道目前只有一个半径 3 m 的圆。
- 还没有声音、参数编辑界面和数据导出。
